# profit_adx_needle 有意性検証スクリプト集

`PRO!fit_ADX_NEEDLE` の**予測的有意性**を実データで検証した記録（2026-07-26）。
実装仕様は `../SPEC.md` / `../README.md` を参照。本ディレクトリは検証手法と実測結果のみを扱い、
`../src/` は一切変更していない。

`market_profile/analysis`・`ma_marod/analysis` の前例に倣い、検証コードを恒久保存する。

## 前提

- Python: `lightweight-charts-python-main/.venv/bin/python`（pandas / numpy 必須。scipy は不使用）
- データ: `data/marketdata/rollups/jp225_m1_{1D,4h,1h,5m}.csv`（JP225, 2012-06〜2026-07）
- パスはリポジトリ相対（`_ROOT = Path(__file__).resolve().parents[3]`）。実行はどのディレクトリからでも可
- 出力は `out/` へ。HTTP サーバ・外部サービスは不要（CSV 直読み）

## 検証設計の骨子

Step 1 で確定した対象の実体:

```
needle = 7 × (ADX(6) の直近120本 因果 z スコア)
       ├ repaint しない（prefix 再計算との差分 0）
       ├ ±3.29σ クランプは 1 本も発動しない（＝ needle == level_count）
       └ ADX は |+DI − −DI| ベース＝**方向を持たない**（トレンド強度）
```

したがって検定は 3 系統に分ける。

| 系統 | 仮説 | 事前予想 |
|---|---|---|
| H1 方向性 | needle が符号付き将来リターンを予測する | 帰無（ADX は方向を持たない） |
| H2 大きさ | needle が将来変動の大きさを予測する | あり得る |
| H2' 増分 | H2 が「直近ボラ z」で説明できない固有情報か | ADX はレンジ由来のため要検証 |
| H3 条件付き | needle が順張り/逆張りの効き（自己相関）を変調する | ADX 本来の用途 |

**帰無分布は循環ブロック順列**（signal 側のみブロック単位で巡回・並べ替え）。自己相関と
重複窓を保存したまま signal↔target の対応だけを壊す。多重比較は BH-FDR。

## 実測結果（要約・確定値）

### H1 方向性 — 有意性なし

- TF 3 × horizon 5 = 15 検定: 最大 |IC| = 0.0119、BH q<0.05 = **0/15**
- period 3 × window 3 × TF 3 × h 3 = **81 構成**: 生 p<0.05 が **0 件**（偶然期待値 4.0 件を下回る）
- 十分位に単調性なし。上位10%−下位10% 差 = −6.0 / −3.0 / −2.0bp（順列 p = 0.86 / 0.67 / 0.56）

### H2 / H2' 大きさ — 自明なボラで代替可能

| 対象（1h, h=1） | IC | p |
|---|---|---|
| needle | +0.0202 | 0.0025 |
| **トレイリングボラ z（陽性対照）** | **+0.1345** | **0.0005** |
| needle の増分（ボラ z の順位効果を除去後） | +0.0147 | BH q<0.05 = 0/15・81 構成でも 0 |

陽性対照が needle の 5.6〜7.6 倍で検出される＝**非有意は検定機構の不備ではない**。

### H3 条件付き — 統計的には頑健、しかし needle 固有ではない

1D のみ交互作用が有意（`r[t+1] = a + b1·r[t] + b2·(r[t]×needle[t]) + b3·needle[t]`、
b2 < 0 ＝ needle が高いほど日次の平均回帰が強い）。

| 検証 | 結果 | 判定 |
|---|---|---|
| ブロック順列 p | 0.0090 | 通過 |
| period×window 9 構成 | 9/9 符号一致（負）、順列 p<0.05 が 7/9 | 通過 |
| COVID(2020Q1)/2020 年 除外 | t=−2.20 (p=0.028) / −2.15 (p=0.044) | 通過 |
| Winsorize 1/2.5/5% | t=−3.09〜−3.53（刈るほど強まる） | 通過（外れ値駆動でない） |
| 順位版 | t=−3.31 (p=0.0025) | 通過 |
| leave-one-year-out | 最大変化 +0.50（単一年依存なし） | 通過 |
| **期間分割** | 前半 t=−0.38 (p=0.72) / 後半 t=−3.43 (p=0.0025) / 直近2年 p=0.19 | **不通過（レジーム依存）** |
| **変調子の置換** | needle t=−2.65 / **素の ADX t=−2.93** / ボラ z t=−0.92 | **不通過（needle 固有でない）** |

### 経済性とウォークフォワード

| 逐次 WF（毎年アンカー拡張窓で閾値再選択・OOS 合成） | 平均 | 年率 Sharpe | WF 順列 p |
|---|---|---|---|
| needle | +22.65bp (n=294) | +2.12 | **0.0519** |
| **素の ADX** | **+32.00bp (n=200)** | **+3.37** | 0.0539 |
| ボラ z（自明な対照） | +13.72bp (n=450) | +1.21 | 0.0758 |

4h / 1h は往復コスト 4.9bp に対し効果が小さく、全ルール・全条件で費用負け。

## 総合判定

**有意性なし。**

1. 方向性は完全否定（81 構成で生 p<0.05 が 0 件）。
2. 大きさ情報はトレイリングボラで代替でき、増分は BH 補正後ゼロ。
3. 条件付き効果のみ統計的頑健性は高いが、(a) ウォークフォワード順列 p≈0.052 で有意水準未達、
   (b) 2012-2017 に完全不在、(c) **素の ADX のほうが強い**。
4. **7 倍スケール・σ バンド・±3.29σ クランプはいずれも順位不変または非発動**で予測力に寄与しない。
   ADX の条件付け効果を使うなら `compute_adx` を直接使うほうがよい（実測で上位）。

## 結果解釈の前提・限界（未検証事項）

- JP225 単一銘柄のみ。他銘柄・他資産クラスへの一般化は未検証。
- 執行は終値約定前提。滑り・ファンディングは未控除。
- WF の閾値グリッドは分位 0.90 が上端で**境界選択**されており、より極端な分位は未走査。
- 本検証全体で約 300 検定を実施している。H3 の p 値はこの探索全体の多重性を補正していない
  （補正すればさらに弱まる）。
- Step 4 出力の `t値` 列は平均/標準誤差 × √n であり年率 Sharpe ではない（年率 Sharpe は
  Step 7 / Step 8 の値を参照）。
