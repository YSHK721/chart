# period_hl — 期間高安 / 年初来高安

価格ラダー（`/dashboard` 第 1 表）へ「期間の走行高安」を水準として供給する指標スライス
（ISSUE-490）。2 つの indicatorId を持つ。

| indicatorId | 系列 | 意味 |
|---|---|---|
| `period_hl` | `period_hl_hi` / `period_hl_lo` | 各バーの high / low。最終バー＝形成中足なので、末尾値がその時間足の**進行中期間の走行高安**（1h 足なら「この 1 時間のこれまでの高安」）になる |
| `ytd_hl` | `ytd_hl_hi` / `ytd_hl_lo` | 暦年（バー時刻＝naive UTC）内の走行 max / min。末尾値が**年初来高安** |

## 設計上の要点

- **期間境界を持たない**。1h / 4h / 1D / 1W の期間境界はロールアップのグリッド
  （marketdata・4h はセッション日起点＝ISSUE-489）が唯一源であり、本指標はバーの
  high / low を読むだけでそれを継承する（境界ロジックの複製ゼロ）。
- **年初来は窓の最初の年を NaN にする**。その年のバーが年初から揃っているかをデータだけ
  からは保証できないため（`1D` 足＝2,000 本で運用する想定。窓が年境界を覆わない足では
  系列が空になり、誤った「年初来」を無言で出さない）。
- 時刻解決・NaN 除外は共有プリミティブ `common_view.lwc_adapter` へ委譲（複製ゼロ）。

## 使い方（価格ラダーへ載せる）

チャート UI で各時間足のテンプレートへ指標を追加する:
1h（`period_hl`）→ 1 時間高安 / 4h → 4 時間高安 / 1D → 日高安 / 1W → 週高安 /
1D（`ytd_hl`）→ 年初来高安。
