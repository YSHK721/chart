# 記法: 1 行 1 件。`+ パターン` = 走査対象に加える / `- パターン` = 除外する。
#       パターンはリポジトリ根からの相対パス（POSIX 区切り）に対する glob。
#       `**` は 0 個以上のディレクトリ、`*` は区切りを跨がない任意文字列。
#       `#` 始まりと空行は無視する。
#
# 順序: 上から評価し、最後に一致した規則が勝つ（除外の中の例外を書ける）。
# 消費者: tools/codescan/collector.py のみ。CLI の --include/--exclude はこの台帳へ
#         追記する形で働く（台帳を置き換えない）。
