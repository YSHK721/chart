# 真の値幅の β で、この先の値幅の増減を当てられるか（2026-10-31）

依頼（2026-10-31）: 「真の値幅の β の検定に着手しろ」。
前段の提案: 真の値幅の β の符号で、次の 20 本の平均が今より大きくなるかを当てられるか、円環ずらし帰無で検定する。

## 1. 事前登録（実行前に記録・結果を見てから変えない）

### 1.1 データ（`.doc/VALIDATION_PROTOCOL.md` §2）
| 用途 | 系列 | 期間 |
|---|---|---|
| 選ぶ期間（IS） | `rollups/jp225_tick_bid/`（Dukascopy） | 2014-01-01 〜 2020-04-30 |
| 確かめる期間（OOS） | `rollups/jp225_mt5/`（MT5） | 2020-05-01 〜 最後の確定足 |

時間足は 1h・1D。2 系列は連結しない。β はこれらの期間で一度も調整していない。
水準の見積もりにワイルダーの平滑 14 を選んだ前回の比較は同じ期間を見ているので、水準の見積もりの良さの証拠ではない。

### 1.2 系列
- x = 真の値幅 ÷ 前の足の終値 × 100（%）。価格帯による単位の偏りを除く。
- 1h のみ、x を時間帯の中央値で割る（期間ごとに 24 個の係数）。時間帯の周期を残すと、円環ずらしで周期が壊れ、見かけの有意が出るため。
- 計算は期間の終わりまでの足だけで行う。IS は先頭に 2014-01 より前の足を助走に使う。

### 1.3 測る量（足 t ごと）
- β: x の直近 n 本の OLS の傾き（btlm_trail の `rolling_ols_window_end` をそのまま使う）。n = 20・50・100。符号だけを使う（0 は除く）。
- A: 直近 20 本の x の平均。Y: 次の 20 本（t+1〜t+20）の x の平均。W: x のワイルダーの平滑 14。

### 1.4 検定（時間足 2 × n 3 = 6 組）
- 検定 1（依頼どおり）: β > 0 と Y > A の一致率 H。
- 検定 2（水準を除いても残るか）: e = log Y −（a + b log W）。D = β > 0 の e の平均 − β < 0 の e の平均。a・b は IS で時間足ごとに最小二乗で決め、OOS でも同じ値を使う。

検定 1 だけでは足りない理由: β > 0 の足は A が高いことが多く、値幅の平均回帰だけで Y < A に偏る。この偏りは円環ずらしで壊れるので、検定 1 の有意は「水準」の情報でも出る。
そのため「β ならではの情報があるか」は検定 2 で判定する。

### 1.5 帰無と p
- 目的の系列（Y > A、または e）を β に対して円環状にずらす。ずらし幅は [250, N − 250] の一様乱数・1,999 個・seed 20261031。
- 両側 p =（1 + |帰無 − 帰無の平均| ≥ |実測 − 帰無の平均| の回数）÷ 2000。
- IS: 検定ごとに 6 組で Holm 法。0.05 未満を通過。
- OOS: IS を通過した組だけで Holm 法。0.05 未満かつ IS と同じ向きで通過。

### 1.6 判定
- 検定 1 が通過: 値幅の増減の向きと関係がある。H が帰無より低ければ「β と逆に動く」と書く。
- 検定 2 が通過: 水準を除いても β に情報がある。
- 実用: 検定 2 を通過した組について、見積もり ŷ = exp(a + b log W + c·sign β)（c は IS の最小二乗）の外れ（外れの平均 ÷ Y の平均）が、c なしより OOS で 0.5 ポイント以上小さいこと。
- どれも通らなければ「β で当てられるとは言えない」と結論する。閾値はこの後で変えない。

### 1.7 計算量の検定
`beta.py` は平均・β・帰無の計算を注入点で受け、発行回数 − 使った回数 = 0 と、入力を増やしても発行が増えないことを `test_beta.py` で固定する。

## 2. 結果（`tools.measure.tr_beta.run`・出力 `results/tests.csv`）

MT5 の最後の確定足は 2026-10-15 16:00 の 1h 足。p の下限は 0.0005。帰無の一致率はどの組も約 0.50（0.498〜0.505）。

| 1h | 100 | 0.414 | 0.003 | 0.409 | 0.0005 | 通過（β と逆に動く） |

### 2.3 判定（§1.6 の基準のまま）
- 検定 1: 5 組が通過。n = 20 は β と同じ向き、n = 50・100 は β と逆に動く。β の向きと値幅の増減の関係は、n によって符号が変わる。
- 検定 2: 1h の n = 50・100 が通過。向きは負で、β > 0 のほうが水準から見た次の 20 本の値幅が小さい（OOS で約 4〜6%）。
- 実用: 通過した 2 組の外れの改善は 0.04・0.10 ポイントで、基準の 0.5 ポイントに届かない。**不合格**。
- 結論: **β に統計的な情報はあるが、次の 20 本の値幅の見積もりを実用的に良くする大きさではない。**「β が正なら値幅はこの先も増える」という読み方は、n = 50・100 では実測と逆である。

### 2.4 未検証・限界
- 時間帯の係数は期間全体の中央値で決めている（期間内の先読み）。検定の目的は周期を除くことで、売買の再現ではない。
- n = 20 の検定 1 の同じ向きが、窓の作り（β > 0 なら A の中で古い足が低い）だけで説明できるかは測っていない。
- 検定 2 の負の向きの理由は測っていない。推論: n が長い β は W14 より長い期間の水準の情報を持ち、W14 が長い期間の水準より高いときに戻りが起きている。
