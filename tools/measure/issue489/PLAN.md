# ISSUE-489 徹底調査計画（2026-09-05 依頼者指示「まずは徹底的に調査検証しろ」）

**注意（先決め原則）**: 本計画は走査を始める前に固定する。結果を見てから指標・閾値・期間を
差し替えることはカーブフィッティングそのものなので、変更する場合は追補として理由を記す。

## 段階 1: 4h グリッド 3 方式の構造監査（予測と無関係の構造品質）
対象: jp225_tick M1 全史（2012-06〜）＋ jp225_mt5 M1（2020-05〜）
- M-1 混在: セッション（実休場 >100 分で区切る）を跨ぐバー数
- M-2 ギャップ隠蔽: オーバーナイトギャップがバー内部に入る回数・量
- M-3 スロット均質性: バー位置（日内何本目か）ごとの出来高・レンジ中央値の変動係数
- M-4 検証錨: (b)(c) と (a) のセッション畳み OHLCV が完全一致すること（同一素材の切り分けである証明）
- M-5 MT5 再現: jp225_mt5 素材へ (b) を当て、サーバ日先頭バー＝取引 3h・他 5 本＝4h を確認

方式: (a) UTC 床 4h / (b) MT5 式（ブローカー日起点 22:00/21:00 UTC・server_clock 規則）4h /
(c) セッション均等割り（jp225_tick: 267 分 ×5 本・jp225_mt5: 230 分 ×6 本）

## 段階 2: 刻み × 反転情報量の走査（目的関数の実測）
- 素材: jp225_tick M1。**期間分割を先に固定**: IS=2012-06〜2020-12 / OOS=2021-01〜2026-09
- 刻み候補（9 個・固定）: 5m, 15m, 30m, 1h, 2h, 4h(b 式), 267m(c 式), 8h(b 式 2 本結合), 1D(セッション日)
- 指標（2 個・固定・実測済みの主力）: SMA 乖離率(w=50)・EMA 乖離率(w=50)＝MAROD 同型
- シグナル（固定）: 因果ローリング分位 p（窓 500 本・最少 100 本）で p≤0.05（押し目・ロング）／
  p≥0.95（過熱・ショート）。**当該バー除外の因果窓**（continuous_quantile と同規約）
- 評価（固定）: シグナル後の**時計時間**ホライズン 1h / 4h / 24h の先渡しリターン。
  イベントは**非重複**（発生後ホライズン経過まで次を取らない・重なり窓の帰無禁止の既定に従う）
- 判定（固定）: IS で BH(q=0.10) 有意 ∧ OOS で同符号かつ p<0.05 ∧ 隣接刻みと符号一致（台地条件）。
  この 3 条件を満たす刻みのみ「頑健」と呼ぶ。1 つも無ければ「予測力では刻みは選べない」が結論。
