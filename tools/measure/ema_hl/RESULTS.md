# 1 分足 60EMA 安値・高値の線で反応するか（2026-10-23）

依頼（2026-10-23）: 「移動平均線で反応しているように見えるのは錯覚か？」→「1分足 60ema lowers higher」→「60ema安値と高値」。
こちらの解釈: 安値で計算した 60EMA（下の線）と高値で計算した 60EMA（上の線）の 2 本。
下の線に上から触れたら買い、上の線に下から触れたら売る、と見たときに、線の価格に反応があるか。

## 1. 事前登録（実行前に記録・結果を見てから変えない）

### 1.1 データ（`.doc/VALIDATION_PROTOCOL.md` §2）
| 用途 | 系列 | 期間 |
|---|---|---|
| 選ぶ期間（IS） | `jp225_tick_bid_m1.csv`（Dukascopy・bid・1 分足） | 2014-01-01 〜 2020-04-30 |
| 確かめる期間（OOS） | `jp225_mt5_m1.csv`（OANDA MT5・1 分足） | 2020-05-01 〜 最後の足 |

EMA は各系列の先頭から計算し（初期値の影響を消す）、事象は期間の中だけで数える。2 系列は連結しない。

### 1.2 線
- 下の線 L = 安値の 60EMA、上の線 U = 高値の 60EMA。定義は参照実装
  `indigators/moving_averages/src/core.py::exponential_ma_on_buffer`（初期値 = 最初の値・係数 2/61）と同じ。
- 形成中の足の線に触れる条件は、EMA の代数的同値により「前の足の線の値に触れる」と同じ
  （安値が L[i−1] 以下 ⇔ 形成中の L[i] に触れる）。約定価格は前の足の線の値。

### 1.3 事象（触れた足 i）
- 下の線（買い）: 始値 > L[i−1] かつ 安値 ≤ L[i−1]。建値 L[i−1]。
- 上の線（売り）: 始値 < U[i−1] かつ 高値 ≥ U[i−1]。建値 U[i−1]。
- 先の窓（n 本後まで）が 30 分を超える時間の空白（週末など）をまたぐ事象は除く。

### 1.4 測るもの（各事象・向きつき）
- 損益: 建値から n 本後の終値までの対数収益（買いは +、売りは符号を反転）。n = 5・15・60。単位 bp。
- 持ちこたえ: 触れた足の終値が、触れた側に戻って終わったか（下の線: 終値 > L[i]、上の線: 終値 < U[i]）。

### 1.5 比べる相手 = 偽の線
- 本物の線を価格比で δ = −0.10%・−0.05%・+0.05%・+0.10% ずらした 4 本（L·(1+δ)、U·(1+δ)）。
  同じ規則で事象・損益・持ちこたえを数える。
- 差 D = 本物の平均 − 偽の線 4 本の平均の平均。D > 0 が「線に反応がある」向き。

### 1.6 検定
- 日単位のブロックブートストラップ（日を復元抽出・1,999 回・seed 20261023）で D の分布を作り、
  片側 p =（1 + D* ≤ 0 の回数）÷ 2000。日の中のつながりは保たれる。
- 選ぶ期間: 2 本の線 × 4 指標（損益 n = 5・15・60、持ちこたえ）= 8 検定に Holm 法。0.05 未満を通過。
- 確かめる期間: 通過したものだけを同じ向きで検定し、Holm 法で 0.05 未満を「再現した」とする。
- 費用: 再現したものは、本物の損益の平均を MT5 の最頻の気配幅 50 point（価格比）と比べる。
