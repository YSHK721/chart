# 足の並びの有意性（2026-10-19）

依頼（2026-10-19）: 「バーの組み合わせの有意性について徹底的に調査報告しろ」。
依頼者の選択: 「足の並び」＝連続する足を陽線・陰線と実体の大きさで分類した並び。

## 1. 事前登録（実行前に記録・結果を見てから変えない）

### 1.1 データ（`.doc/VALIDATION_PROTOCOL.md` §2 の割り当て）

| 用途 | 系列 | 期間 |
|---|---|---|
| 選ぶ期間（IS） | `rollups/jp225_tick_bid/jp225_tick_bid_{tf}.csv`（Dukascopy・bid） | 2014-01-01 〜 2020-04-30 |
| 確かめる期間（OOS） | `rollups/jp225_mt5/jp225_mt5_{tf}.csv`（OANDA MT5） | 2020-05-01 〜 最後の確定足 |

- 2 系列は連結しない。各期間の中だけで計算する。
- 時間足 tf: 15m・1h・4h・1D。
- 日足は土曜・日曜のラベルの足（週末の短い足）を除く。
- 各系列の最後の 1 本は形成中の可能性があるので除く。

### 1.2 足の分類
- 向き: 終値 > 始値 → 陽（U）、終値 < 始値 → 陰（D）、終値 = 始値 → 同値。
  **同値の足を含む並びは数えない。**
- 大きさ: |終値 − 始値| が、その足より前の 100 本の |終値 − 始値| の中央値以上 → 大、未満 → 小。
  前の 100 本がそろうまでの足は分類しない。

### 1.3 並び
- 族 A（向きだけ）: 長さ k = 1〜5（2 + 4 + 8 + 16 + 32 = 62 通り）。
- 族 B（向き × 大きさ）: 長さ k = 1〜3（4 + 16 + 64 = 84 通り）。
- 並びは最後の足の終値で確定する。

### 1.4 測るもの
- 先の値動き: 並びが確定した足の終値から h 本後の終値までの対数収益。h = 1・4。
- 統計量: t = (並びの後の平均 − その期間の全足の平均) ÷ (並びの後の標準偏差 ÷ √n)。
  全足の平均を引くのは、上昇相場の流れ（ドリフト）を並びの効果と取り違えないため。
  並びの後の標準偏差で割るのは、大きい足の後は値動きも大きいため。
- 出現が 30 回未満の並びは検定しない。

### 1.5 比べる相手（帰無）
- 先の値動きの列を、並びの列に対して円環状にずらす（ずらし幅は 500 〜 n − 500 から無作為・999 本・seed 20261019）。
  値動きのつながり（自己相関・大きさの固まり）と並びの出方の固まりは、どちらも保たれる。
  並びと先の値動きの対応だけが壊れる。
- p（両側）=（1 + |帰無の t| ≥ |本物の t| の本数）÷ 1000。

### 1.6 判定
1. 選ぶ期間: 全検定（4 時間足 × 2 本数 × 146 通り）に BH 法（偽発見率の補正）をかけ、q < 0.05 を通過とする。
2. 確かめる期間: 通過した並びだけを、選ぶ期間と同じ向きで片側検定する。Holm 法で補正し、0.05 未満を「再現した」とする。
3. 全体検定（並びの情報が全体として有るか）: 時間足 × 本数ごとに S = Σ t²（検定対象の並びすべて）を、同じずらしの帰無と比べる。両期間で別々に出す。
4. 費用: 確かめる期間で再現した並びは、平均の差を MT5 の最頻の気配幅 50 point（価格に対する比）と比べる。

### 1.7 修正（2026-10-19・1 回目の実行の後・個別の並びの結果を見る前に記録）

**欠陥**: 帰無 999 本では p の最小値が 0.001 になる。1,060 検定に BH 法をかけると、本当に効く並びが
1 つだけなら q の最小は 0.001 × 1060 = 1.06 で、**どれほど強くても通過できない**
（通過には 22 件以上が同時に p = 0.001 になる必要がある）。§1.6 の 1 は検出力を持たない手順だった。
1 回目の実行で見たのは「BH 通過 0 件」と全体検定の表（§2.1）だけで、個別の並びの t・p は見ていない。

**修正**: 個別の判定を、時間足 × 本数ごとの**最大 |t| の帰無**（同じずらし 999 本で、全並びの |t| の最大値の分布）で行う。
- p_fw =（1 + 帰無の最大 |t| ≥ 本物の |t| の本数）÷ 1000。並び同士の相関をそのまま保つ補正（Westfall–Young の単段 maxT）。
- 8 個（4 時間足 × 2 本数）の族に Bonferroni をかけ、p_fw ≤ 0.05 / 8 を選ぶ期間の通過とする。
- 確かめる期間の判定（§1.6 の 2）・全体検定（§1.6 の 3）・費用（§1.6 の 4）は変えない。

### 2.3 検出力（見逃していない大きさ）

### 2.4 分かっていないこと

- 並びの定義（大きさの境目＝前 100 本の中央値・長さの上限）を変えた場合は測っていない。
- ひげ（上ひげ・下ひげ）の形は分類に入れていない（名前のある型は依頼者の選択の外）。


## 3. ひげを入れた並び — 事前登録（2026-10-19・実行前に記録）

依頼（2026-10-19）: 「ひげ（上ひげ・下ひげ）の形を分類に入れろ」。
§1 と同じデータ・期間・先の値動き・統計量・帰無・判定（§1.7 の maxT と Bonferroni 8）を使う。変えるのは並びの族だけ。

### 3.1 ひげの分類
- 上ひげ = 高値 − max(始値, 終値)、下ひげ = min(始値, 終値) − 安値。
- 各ひげが、その足より前の 100 本の同じひげの中央値以上 → 長、未満 → 短（実体の大きさと同じ作り方）。
- ひげの形は 4 種類: 上長下長・上長下短・上短下長・上短下短。

### 3.2 並び（新しい族だけで検定する。§2 の族 A・B は含めない）
- 族 C（向き × ひげ・8 記号）: 長さ k = 1・2（8 + 64 = 72 通り）。
- 族 D（向き × 大きさ × ひげ・16 記号）: 長さ k = 1・2（16 + 256 = 272 通り）。
- 長さ 3 は入れない（D の 3 本は 4,096 通りで、日足では大半が出現 30 回未満になるため）。
- 最大 |t| の帰無は、時間足 × 本数ごとに族 C・D の検定対象すべてで取る。

### 3.3 判定
§1.6 の 2〜4・§1.7 と同じ。選ぶ期間で p_fw ≤ 0.05 / 8 の並びだけを確かめる期間で片側検定（Holm）。
全体検定は族 C・D の検定対象すべての Σ t²。

### 4.2 情報の中身（検定外の観察）
両期間で同じ向きに出た並びは、1 本だけの形が中心（15m・1 本後）:

| 並び | IS 差（bp） | IS t | OOS 差（bp） | OOS t |
|---|---|---|---|---|
| 陰・上長下短 | +0.43 | 3.56 | +0.26 | 2.38 |
| 陽・上長下短 | +0.29 | 2.62 | +0.21 | 2.15 |
| 陽・上短下長 | −0.26 | −2.27 | −0.32 | −3.19 |
| 大陽・上短下長 | −0.49 | −3.04 | −0.31 | −2.01 |

上ひげが長い（終値が足の下寄り）と次の足は上へ、下ひげが長い（終値が上寄り）と次の足は下へ、わずかに戻る。
**大きさは 0.2〜0.5 bp で、費用 14.0 bp（MT5 最頻の気配幅 50 point ÷ OOS 平均終値 35,733）の 1/30 以下。**
推論（未検証）: bid 系列の終値が気配の中で跳ね返る、足の中の位置の小さな戻り。

### 4.3 結論
ひげの形には、次の 1 本へのごく小さい戻りの情報が両期間で見える。しかし個別に再現した並びは無く、
効果は費用の 1/30 以下で、売買には使えない。
