# subagent-creator 出力テンプレート

subagent-creator スキル §6 結果出力から参照される出力テンプレート集。
モード（[A] 新規作成 / [B] 既存レビュー / [C] 委譲先選定）と異常時に応じて該当テンプレートを使用する。

> **出力形式の絶対要件**：出力は **マークダウンとして直接レンダリングされる形で出力する**。出力全体を ` ``` `（トリプルバッククォート）で囲むことを禁止する。表・見出し・絵文字判定アイコンが視認可能な状態でユーザーに表示される必要がある。

### 出力時の遵守事項

| # | ルール | 違反例 | 正例 |
|---|--------|--------|------|
| 1 | 出力全体をコードフェンスで囲まない | ` ```\n# 【レビュー結果】...\n``` ` | `# 【レビュー結果】...`（フェンスなし） |
| 2 | 区切り線は `---`（マークダウン水平線） | `━━━━━━━━━` 等の罫線文字 | `---` |
| 3 | 表は GFM テーブル記法 | スペース区切り | `\| 列 1 \| 列 2 \|` |
| 4 | 見出しは `#` `##` `###` | `**【見出し】**` | `## 欠陥サマリー` |
| 5 | 判定アイコン（🔴 / 🟡 / ✅ / 🔵）は本文中に直接記述 | アイコンのコード化 | 本文中に直接記述 |
| 6 | YAML / Markdown を含む修正案のみ部分的にコードフェンス | 全体をフェンス | 該当ブロックのみフェンス |
| 7 | 観点 1〜11 すべてに見出しと判定 4 行を出力 | 「問題なし」観点の省略 | 全 11 観点を明示 |
