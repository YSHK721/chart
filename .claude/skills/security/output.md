## 出力時の遵守事項

- 9 章すべてを埋めること。空欄は許容しない（該当なしの場合は「該当なし」と明記）
- 章番号・章タイトルはテンプレート通りに保持する（SKILL.md §4「出力テンプレート参照」ルール準拠）
- 各章の内容は `${CLAUDE_SKILL_DIR}/SKILL.md` §5 実行プロセスの各ステップ（S-1〜S-7）の出力に準拠する
- 必須対策は `${CLAUDE_SKILL_DIR}/references/threat-catalog.md` から、ツール選択は `${CLAUDE_SKILL_DIR}/references/tool-matrix.md` から、レビュー判定は `${CLAUDE_SKILL_DIR}/references/review-checklist.md` から、更新規則は `${CLAUDE_SKILL_DIR}/references/threat-info-update.md` から引用する
- 設計判断には OWASP / DBIR / Sonatype / プロジェクト規約 / 仮説 のいずれかを併記する（SKILL.md §4「出典明示」ルール準拠）
- 実務派生（運用手順・組織別カスタマイズ）は「（実務的推奨／仮説）」と注記する（SKILL.md §4「仮説明示」ルール準拠）
- 異常時は本テンプレートを使用せず、SKILL.md §6「異常時の出力」の `[SECURITY-DESIGN-HALT]` フォーマットで中断報告する
- 主観・感想（「強固な対策」「優れたツール」等）は出力しない（SKILL.md §4「主観禁止」ルール準拠）
- 曖昧表現（「適切に」「効率的に」「柔軟に」「適宜」「一般的に」「速やかに」「リアルタイム」）は使用しない（SKILL.md §4「曖昧表現禁止」ルール準拠）
- 数値で表現可能な閾値（CVSS スコア・パッチ期限・有効期限）はすべて数値で明示する
