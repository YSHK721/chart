# レビューチェックリスト（優先度付き）

security スキル §5 実行プロセス S-6（レビュー実施）から参照される優先度付きチェックリスト。
判定基準は「合格 = すべての判定基準を満たす」「不合格 = 1 件でも判定基準を満たさない」とする。

---

## 🔴 Critical（マージブロッカー）

| 検出項目 | 判定基準 |
|---|---|
| 機密情報のハードコーディング | API キー・パスワード・トークンがソースコードに直接記述されていないこと |
| SQL インジェクション脆弱性 | パラメータ化クエリまたは ORM プリペアドステートメントを使用していること |
| 認証・認可の完全なバイパス | 全エンドポイントで認証・認可チェックが実行されること |
| 重大脆弱性を持つ依存関係 | CVSS 9.0 以上の既知脆弱性を持つ依存関係が 0 件であること |

## 🟡 High（必須修正）

| 検出項目 | 判定基準 |
|---|---|
| XSS 脆弱性 | 入力検証および出力エスケープが実装されていること |
| 不適切なエラーハンドリング | エラーレスポンスにスタックトレース・内部パス・SQL 文が含まれないこと |
| 弱い暗号化アルゴリズム | MD5・SHA-1・DES・3DES・RC4 を使用していないこと |
| 高脆弱性を持つ依存関係 | CVSS 7.0–8.9 の既知脆弱性を持つ依存関係が 0 件であること |

## 🟢 Medium（推奨修正）

| 検出項目 | 判定基準 |
|---|---|
| セキュリティヘッダ | CSP・HSTS・X-Content-Type-Options・X-Frame-Options が設定されていること |
| 監査ログ | 認証失敗・特権操作・権限変更のすべてが記録されていること |
| 入力値検証の不完全性 | 型・範囲・フォーマット・長さの全観点で検証が実装されていること |
| 中脆弱性を持つ依存関係 | CVSS 4.0–6.9 の既知脆弱性が次パッチリリースまでに解消される計画があること |
