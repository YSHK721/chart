## 1. 主張 (Claim, C)

### 定義
議論の結論として正当化されるべき命題。書き手が読み手に受け入れさせたい中心的な宣言。

### 公式出典
Toulmin (1958/2003)：「我々が何かを主張する場合、我々はその主張を正当化する用意がなければならない」

### 典型例
- 「この投資は利益を生む可能性が高い」（事実主張）
- 「この行為は倫理的に許容されない」（価値主張）
- 「政策Xを採用すべきである」（政策主張）

### 主張の5つの型

| 型 | 例 |
|----|-----|
| 事実 (fact) | 「気温は上昇している」 |
| 定義 (definition) | 「これはハラスメントに該当する」 |
| 価値 (value) | 「自由は安全より重要である」 |
| 原因と結果 (cause & effect) | 「Xを行えばYが起こる」 |
| 政策 (policy) | 「Xを採用すべきである」 |

### 抽出のコツ
- 「したがって」「ゆえに」「結論として」の後に続く文を探す
- 文章全体が説得しようとしている中心命題を1〜2文で要約する
- 複数の主張がある場合、最も包括的な主張を「メイン主張」、その他を「サブ主張」として階層化する

## 2. データ (Data, D)

### 定義
主張を支える具体的な事実・統計・事例・証言。「何に基づいて主張するか」を示す。

### 公式出典
Toulmin (1958/2003)：「データは主張の基礎となる事実である」

### 典型例
- 統計：「2024年の調査で〇〇%が…」
- 事例：「企業Xでは△△が起きた」
- 証言：「専門家のZ氏は…と述べている」
- 直接観察：「実験で〇〇が観測された」

### 抽出のコツ
- 「なぜなら」「〜という事実から」「〜のデータによれば」の後に続く情報を探す
- 主張の根拠として提示されている具体的・検証可能な情報を識別する
- 出典が明示されているか確認する（未明示の場合は弱点として記録）

### データの強度評価

| 評価軸 | 強い | 弱い |
|--------|-----|-----|
| 出典 | 査読論文・公式統計 | 個人ブログ・伝聞 |
| 量 | 複数の独立した情報源 | 単一情報源 |
| 直接性 | 直接観察・一次資料 | 引用の引用・伝聞 |
| 時間的妥当性 | 直近・現行 | 古い・状況変化あり |

## 3. 保証 (Warrant, W)

### 定義
データから主張への移行を許可する一般原則・規則。「なぜこのデータからこの主張が導けるのか」を説明する。「推論の免許 (inference-licence)」とも呼ばれる。

### 公式出典
Toulmin (1958/2003)：「保証は、データから主張への移行を正当化する仮想的な命題である」

### 典型例
- データ：「Xは硫酸銅である」
- 保証：「硫酸銅は青色である」（一般原則）
- 主張：「Xは青色である」

- データ：「住宅価格が3年連続で上昇している」
- 保証：「過去のトレンドは将来の傾向を示唆する」（推論原則）
- 主張：「住宅価格は来年も上昇する可能性が高い」

### 抽出のコツ
- データから主張への「論理的な飛躍」を埋める原則を探す
- 多くの場合、文章中で明示されていない（暗黙の前提として扱われる）
- 明示されていない場合は「（推測）」として再構成する
- 「〜という原則に基づき」「〜という規則により」という表現があれば保証の候補

### 保証が暗黙のままだと危険な理由

保証が明示されないと、読み手は次のいずれかの状態に置かれる。
- 書き手と同じ前提を共有している場合：問題なく主張を受け入れる
- 前提を共有していない場合：飛躍を感じ、主張を拒否する

書き手の責務は、読み手が共有しない可能性のある保証を明示することである。

## 4. 裏付け (Backing, B)

### 定義
保証そのものに権威・信用を与える、さらなる理論・統計・先例・専門知識。

### 公式出典
Toulmin (1958/2003)：「我々の保証が疑問視された場合、我々は裏付け（backing）に頼る」

### 典型例
- 保証：「過去のトレンドは将来の傾向を示唆する」
- 裏付け：「経済学における市場慣性の理論（〇〇研究, 20XX）」

- 保証：「合理的な医師は同様の状況で同様の処置を行う」
- 裏付け：「医療判例X v. Y における判決原則」

### 抽出のコツ
- 保証を「なぜ受け入れるべきか」を支える、より深い根拠を探す
- 学術論文では参考文献として明示されることが多い
- 法的議論では判例・条文として明示される
- 議論領域（field of argument）によって、何が裏付けとして妥当かが異なる

### 領域依存性（field-dependent）

| 議論領域 | 妥当な裏付けの種類 |
|---------|------------------|
| 科学 | 査読論文・実験データ・メタ分析 |
| 法律 | 判例・条文・法理論 |
| 倫理 | 倫理理論・社会的合意・哲学的論証 |
| 日常会話 | 慣習・経験則・常識 |
| 工学 | 規格・実装事例・設計理論 |

裏付けが議論領域に適合していない場合、論証は説得力を失う。

## 5. 限定子 (Qualifier, Q)

### 定義
データに基づいた主張がどの程度の強さ・確実性を持っているかを示す語。

### 公式出典
Toulmin (1958/2003)：「限定子は、保証から主張への進み方の強さを示す」

### 確実性レベル別の典型語

| レベル | 限定子 |
|-------|--------|
| 必然的 | 「必然的に」「確実に」「明らかに」 |
| 高確率 | 「ほぼ確実に」「ほぼ間違いなく」「強い確信を持って」 |
| 中程度 | 「おそらく」「多分」「通常」「一般的に」 |
| 範囲限定 | 「多くの場合」「典型的には」「ほとんどの場合」 |
| 部分適用 | 「一部の」「特定の条件下では」「場合によっては」 |

### 限定子のパラドックス

主張の適用範囲をあえて狭めることで、かえって反論されにくくなる。これは「限定語のパラドックス」と呼ばれる。

| 主張 | 反論余地 |
|-----|---------|
| 「ディケンズの本は面白い」（無限定） | 1冊でも退屈な本が見つかれば論破 |
| 「ディケンズの多くの本は面白い」（限定子あり） | 数冊の例外があっても主張は維持 |

### 抽出のコツ
- 主張文の修飾語を確認する
- 限定子が欠落している場合、暗黙の「必然的に」が仮定されており、過剰断定の可能性が高い
- 議論領域に応じて適切な限定子のレベルを判定する

## 6. 反駁 (Rebuttal, R)

### 定義
保証が適用されない例外的状況。主張が覆される可能性のある条件をあらかじめ提示する。

### 公式出典
Toulmin (1958/2003)：「反駁は、保証の権威が脇に置かれるような状況を示す」

### 典型例
- 主張：「鳥は飛ぶことができる」
- 反駁：「ただし、ペンギン・ダチョウ・キウイ等の飛べない鳥を除く」

- 主張：「企業Xは健全な成長を続けるだろう」
- 反駁：「ただし、経営陣の重大な不祥事や規制変更がない場合に限る」

### 反駁の4パターン

| パターン | 形式 | 例 |
|---------|------|-----|
| 例外条件 | 「ただし〜の場合を除いて」 | 「ただし極寒地域を除き」 |
| 適用範囲 | 「〜という条件下では」 | 「室温20〜25°Cの条件下では」 |
| 反対証拠 | 「もし〜という証拠があれば」 | 「もし新規参入企業が現れれば」 |
| 異論対応 | 「〜という反論がありうるが、それに対しては〜」 | 「環境負荷を懸念する向きもあるが、本研究は…」 |

### 抽出のコツ
- 「ただし」「もっとも」「しかし」「except that」等の表現を探す
- 反駁が明示されていない場合、書き手が例外を想定していない可能性を指摘する
- 主要な反駁が欠落している論証は、批判に対して脆弱

## 7. 6要素の階層構造と相互関係

```
                    [主張 C]
                    限定子 Q（強さ）
                       │
                       │ なぜなら
                       │
                    [データ D]
                       │
                       │ なぜならば（移行を許可）
                       │
                    [保証 W]
                       │
                       │ なぜならば（権威の根拠）
                       │
                    [裏付け B]

                       ⊥ (反駁 R が適用される条件)
```

### 「トランプの城」のメタファー

論証は階層構造であり、上位要素は下位要素に支えられる。

- 主張 (C) は データ (D) に支えられる
- データ (D) と主張 (C) の橋渡しを 保証 (W) が行う
- 保証 (W) は 裏付け (B) によって権威付けされる
- 限定子 (Q) は主張全体の強度を制御する
- 反駁 (R) は適用範囲を限定する

下位要素が崩れると、上位要素も崩壊する。

## 8. 抽出時の典型的な混同パターン

### パターン1：データと保証の混同

❌ 誤った抽出：
- データ：「鳥は飛ぶことができる」
- 主張：「この生物は飛ぶことができる」

✅ 正しい抽出：
- データ：「この生物は鳥である」
- 保証：「鳥は飛ぶことができる」（一般原則）
- 主張：「この生物は飛ぶことができる」

判別基準：データは**具体的・個別的**、保証は**一般的・規則的**。

### パターン2：保証と裏付けの混同

❌ 誤った抽出：
- 保証：「査読論文Xでこのメカニズムが報告された」
- 裏付け：「したがってこのメカニズムは正しい」

✅ 正しい抽出：
- 保証：「査読された科学的知見は受け入れるに値する」（推論原則）
- 裏付け：「査読制度の歴史的有効性（科学方法論）」

判別基準：保証は**データから主張への橋渡し**、裏付けは**保証の権威の根拠**。

### パターン3：主張と結論の混同

データに含まれる情報がそのまま主張になっている場合、それは「分析的議論」であり、新しい情報を生んでいない。

詳細は `analytic-vs-substantial.md` 参照。

### パターン4：限定子と反駁の混同

- 限定子は**主張の強度**を調整する（「おそらく」「多くの場合」）
- 反駁は**主張の適用範囲**を限定する（「ただし〜を除く」）

両者は連携して機能するが、機能は異なる。
