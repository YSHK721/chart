## 1. 限定子の選択フロー

主張に付与する限定子を以下のフローで決定する。

```
[Step 1] データの強度を評価
   │
   ├─ データが網羅的・確実 → 「必然的に」「確実に」
   ├─ データが大多数を支持 → 「ほぼ確実に」「強い確信を持って」
   ├─ データが多数を支持   → 「おそらく」「多くの場合」
   ├─ データが一部を支持   → 「一部の場合」「特定の条件下では」
   └─ データが不十分       → 限定子では補えない（データ追加が必要）

[Step 2] 議論領域の慣習を確認
   │
   ├─ 科学：「現時点の知見では」「複数の研究で示唆されている」
   ├─ 法律：「判例に基づけば」「合理的な解釈として」
   ├─ 倫理：「多くの倫理理論において」「一般的な道徳直観として」
   └─ 日常：「通常」「多くの人が」

[Step 3] 反駁との整合性を確認
   │
   └─ 反駁が明示する例外と限定子の範囲が整合しているか
```

## 2. 限定子の確実性レベル別パターン

### レベル1：必然的（必然性主張）

| 限定子 | 使用条件 |
|-------|---------|
| 「必然的に」 | 論理的・数学的に導かれる結論 |
| 「確実に」 | 直接観察・実験で確認された事実 |
| 「明らかに」 | 共有された前提から直接導かれる |

⚠️ 注意：実質的議論（経験的議論）でこれらを使うのは過剰断定のリスクが高い。

### レベル2：高確率

| 限定子 | 使用条件 |
|-------|---------|
| 「ほぼ確実に」 | 95%以上の信頼度を持つデータ |
| 「ほぼ間違いなく」 | 複数の独立した強いデータが一致 |
| 「強い確信を持って」 | 専門的判断として高い信頼度 |

### レベル3：中程度

| 限定子 | 使用条件 |
|-------|---------|
| 「おそらく」 | 過半数の支持を持つ予測 |
| 「多分」 | 日常会話レベルの推測 |
| 「通常」 | 標準的なケースでの判断 |

### レベル4：範囲限定

| 限定子 | 使用条件 |
|-------|---------|
| 「多くの場合」 | 主流のケースに該当 |
| 「典型的には」 | 標準パターンに該当 |
| 「一般的に」 | 広く認められた傾向 |
| 「ほとんどの場合」 | 例外を除く大部分 |

### レベル5：部分適用

| 限定子 | 使用条件 |
|-------|---------|
| 「一部の」 | 限定された範囲のみ |
| 「特定の条件下では」 | 明示された条件付き |
| 「場合によっては」 | 状況に依存する |

## 3. 反駁の4パターン詳細

### パターン1：例外条件 (Exception)

**形式**：「ただし〜の場合を除いて」「except when 〜」

**用途**：主張が成立しない既知の例外を明示する。

**例**：
- 「鳥は飛ぶことができる、ただしペンギン・ダチョウ・キウイ等の例外を除く」
- 「契約は法的拘束力を持つ、ただし強迫・詐欺・錯誤による締結を除く」

**使い分け基準**：例外が**離散的に列挙可能**な場合に使う。

### パターン2：適用範囲 (Domain Restriction)

**形式**：「〜という条件下では」「under conditions of 〜」

**用途**：主張が成立する条件を明示し、その外では成立しないことを示す。

**例**：
- 「水は100°Cで沸騰する、ただし標準気圧（1気圧）の条件下で」
- 「自由市場は効率的である、ただし完全競争市場の条件下で」

**使い分け基準**：例外が**連続的・条件依存的**な場合に使う。

### パターン3：反対証拠 (Counter-evidence)

**形式**：「もし〜という証拠があれば」「if evidence of 〜 emerges」

**用途**：主張が覆される可能性のある将来的証拠を明示する。

**例**：
- 「住宅価格は上昇を続けるだろう、もし金利が大幅に上昇しなければ」
- 「この治療は有効である、もし新たな有害事象が報告されなければ」

**使い分け基準**：主張が**将来予測・継続的判断**である場合に使う。

### パターン4：異論対応 (Counter-argument)

**形式**：「〜という反論がありうるが、それに対しては〜」

**用途**：予想される反対意見をあらかじめ提示し、それに対する再反論を行う。

**例**：
- 「環境負荷を懸念する向きもあるが、本研究のライフサイクル分析では正味の環境利得が示されている」
- 「コスト増を懸念する声もあるが、長期的には保守費削減で相殺される」

**使い分け基準**：論証が**論争的な領域**にあり、明確な対立意見が存在する場合に使う。

## 4. 限定子と反駁の連携

限定子と反駁は独立した要素だが、組み合わせて使うことで論証はさらに強化される。

### 強化パターン1：限定子で確率調整＋反駁で範囲限定

```
主張：政策Xは経済成長を促す
↓
限定子：「おそらく」 → 主張：政策Xはおそらく経済成長を促す
↓
反駁：「ただし金融危機が発生しない限り」 → 主張：政策Xはおそらく経済成長を促す、ただし金融危機が発生しない限り
```

### 強化パターン2：複数の反駁を階層化

```
主張：この投資は利益を生む
反駁1（例外条件）：ただし、対象企業の経営陣が大幅に変動した場合を除く
反駁2（反対証拠）：もし市場全体が10%以上下落しなければ
反駁3（適用範囲）：3年〜5年の中長期保有の条件下で
```

### 弱体化パターン（注意）

限定子と反駁が**矛盾する**場合、論証は脆弱になる。

❌ 矛盾例：
- 限定子：「確実に」
- 反駁：「ただし多くの例外がある」

✅ 整合例：
- 限定子：「多くの場合」
- 反駁：「ただし以下の例外を除く」

## 5. よくある失敗例

### 失敗1：限定子の欠落（過剰断定）

❌ 「すべての専門家は AI が雇用を奪うと考えている」

問題：限定子なしで「すべての」と断定。一人でも反対意見の専門家がいれば論破される。

✅ 修正：「多くの専門家は AI が一部の雇用を奪うと予測している」

### 失敗2：限定子の過剰使用（主張の希薄化）

❌ 「おそらく、多くの場合、もしかすると、AI は経済に影響を与えうる」

問題：限定子の過剰使用で主張が無内容になる。

✅ 修正：「AI は多くの産業で雇用構造を変化させる可能性が高い」

### 失敗3：反駁の表面的な提示

❌ 「この主張には例外があるかもしれない」（具体的な例外を示さない）

問題：反駁が抽象的すぎて、論証の精度に貢献しない。

✅ 修正：「この主張は標準気圧下で成立するが、高山地帯や深海では沸点が変動するため適用外となる」

### 失敗4：反駁の連鎖による主張の崩壊

❌ 「X は Y を引き起こす、ただし条件Aで、条件Bで、条件Cで、条件Dの場合を除く」

問題：反駁が多すぎて、もはや主張自体が成立しているか不明。

✅ 修正：主張の範囲を限定子で明確にし、主要な反駁のみに絞る。

## 付録：限定子・反駁の選択チェックリスト

論証に限定子・反駁を追加する際、以下を点検する。

- [ ] 限定子はデータの強度に対応しているか
- [ ] 限定子は議論領域の慣習に合致しているか
- [ ] 反駁は具体的に何が例外かを示しているか
- [ ] 限定子と反駁の範囲は矛盾していないか
- [ ] 主要な反論が予測されているか
- [ ] 反駁が多すぎて主張が崩壊していないか
