### UP-2: git diff --cached --stat の確認仕様

**判定基準**: 「git diff --cached --stat で確認」のステップが実装可能か・判定基準が明示されているか

**実証手段**: CLAUDE.md 参照・git diff コマンドの man ページ参照

**実証結果**:
```bash
CLAUDE.md 記載: "コミット前に必ず git diff --cached --stat を読み、意図しないファイルが入っていないか確認"
git diff --cached --stat の動作: ステージングエリアの差分を要約表示
判定基準: 意図しないファイル（環境依存物・秘密鍵など）が含まれていないこと
```

**判定**: ✓ **採用** — 標準 git コマンド・判定基準が明示されている
