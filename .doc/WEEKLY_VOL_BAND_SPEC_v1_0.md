# 週次ボラティリティ・バンド戦略 仕様書

- **バージョン**：1.0（確定版）
- **作成日**：2026-06-23
- **対象**：日経225 現物指数CFD
- **方向**：ロング専用

---

## 1. 概要

- **目的**：週初にロングし、下方半実現ボラ予測から導く経路バリアにストップ、上方半実現ボラ予測の分位点に利確を置き、金曜引けで必ず手仕舞うことで週末ギャップを排除し、損益比を事前確定させる。採否は規定の検証手続きで一意に決定する。
- **スコープ（含む）**：単一銘柄、ロング、週次保有（最長5営業日）、OCO決済、金曜引け強制手仕舞い、パラメータの検証手続きによる自動選択。
- **スコープ（含まない）**：ショート、複数銘柄、週またぎ保有、積み増し、裁量介入。

## 2. インターフェース定義

### 2.1 入力データ

| 名称 | 型 | 制約 | 取得元 |
|---|---|---|---|
| 日足OHLC | float×4/日 | O,H,L,C>0、非取引日除外 | Stooq `^NKX` 等（長期骨格用） |
| 日中5分OHLC | float×4/5分 | 同上、立会時間で集計 | Dukascopy `jpnidxjpy`（半実現分散用、2011-09〜） |
| 配当落ちデータ | float/日 | 指数配当相当 | 指数公式 |

### 2.2 外部入力（ブローカー依存・数値供給が必要）

| 名称 | 記号 | 単位 | 既定 |
|---|---|---|---|
| スプレッド | `c_spread` | 指数%（往復） | 要供給 |
| 手数料 | `c_comm` | 指数%（往復） | 要供給 |
| ファンディング年率 | `r_fund` | %/年（ロング支払） | 要供給 |
| 1取引リスク | `f_risk` | 資本% | **1.0%（固定・探索対象外）** |

### 2.3 固定パラメータ（探索しない＝多重性を抑制）

| 名称 | 記号 | 値 |
|---|---|---|
| ストップ到達目標確率 | `α_stop` | 0.05 |
| 全体ボラ推定量 | — | Garman-Klass（週次集計） |
| 上下分離 | — | 半実現分散 RS⁺/RS⁻（5分リターン符号別二乗和、週次集計） |
| 予測モデル | — | log-semivariance-HAR |
| HAR説明変数 | — | 週次RSの {1週, 4週平均, 12週平均} |
| 推定法 | — | OLS＋Newey-West(lag=4) |
| 推定窓 | — | 260週ローリング |
| 再推定 | — | 毎週末 |
| バリア分布仮定 | — | ドリフトなし対数正規＋鏡像原理 |
| 同一バー両到達 | — | **ストップ優先** |

### 2.4 探索パラメータ（検証手続きで一意選択・全20候補）

| 名称 | 記号 | グリッド |
|---|---|---|
| エントリー規則 | `e` | {E0:無条件} ∪ {E1(θ): 前週close-to-closeリターン ≤ −θ·σ̂ᵗᵒᵗᵃˡ_w, θ∈{0.5,1.0,1.5,2.0}}（計5） |
| 利確到達確率 | `p_tp` | {0.40, 0.50, 0.60, 0.70}（計4） |

- 候補数 = 5 × 4 = **20**。
- 各候補 k の評価統計量 `f_k` = IS区間のコスト控除後・週次純リターン平均。

### 2.5 出力（週次サイクルごと）

| 名称 | 型 | 定義 |
|---|---|---|
| エントリー | {price, side} | 週初寄り、long（規則 `e` が真のとき） |
| ストップ `S` | float | `S = O · exp(−1.96 · σ̂⁻_w)` |
| 利確 `T` | float | `T = O · exp(z(p_tp) · σ̂⁺_w)`、`z(p) = −Φ⁻¹(p/2)` |
| ポジション数量 `N` | float | `N = f_risk · Capital / (O − S)` |
| 決済結果 | enum | {利確, ストップ, 時間切れ} |
| 週次純損益 | float | コスト控除後 |
| ログ | record | §4.2 |

`z(p_tp)` の値：z(0.40)=0.842, z(0.50)=0.674, z(0.60)=0.524, z(0.70)=0.385。

### 2.6 例外・境界（すべて一意に規定）

| 条件 | 挙動 |
|---|---|
| 週初が非取引日 | その週の最初の取引日の寄りでエントリー |
| 金曜が非取引日 | その週の最後の取引日の引けで手仕舞い |
| 寄りが `S` 未満（ギャップ突破） | 寄り値で約定、差をスリッページとして損益に計上 |
| 同一バー内で `S`・`T` 両到達 | ストップ優先 |
| σ̂⁻ または σ̂⁺ 算出不可 | その週ノートレード |
| 推定窓 < 260週 | ノートレード（ウォームアップ） |
| イベント週（日銀/FOMC/SQ/主要指標） | エントリーする。`event=true` でログし別集計 |

## 3. 処理フロー

### 3.1 週次運用サイクル

**週末バッチ（前週金曜引けまでの確定データのみ）**

1. 5分データから各週 RS⁺_w, RS⁻_w を算出。
2. log-semivariance-HAR を推定窓260週で再推定 → 翌週 σ̂⁺_w, σ̂⁻_w を予測。算出不可ならノートレード確定。
3. `S`, `T`, `N` を §2.5 の式で算出。
4. エントリー規則 `e`（検証で確定済み）を前週リターンに適用し、真偽を決定。

**週初（寄り）**

5. 規則真なら寄り成行でロング `N` 単位、同時に OCO（`S`成行ストップ＋`T`指値）を発注。

**週内（火〜金）**

6. `S`・`T` のうち時系列で先に到達した方で決済。両未到達なら継続。

**金曜（引け）**

7. 未決済なら引け値で強制手仕舞い（結果=時間切れ）。
8. 純損益 = (決済価格 − エントリー価格)·N − c_spread − c_comm − r_fund·(保有日数/365)·建玉額 ± 配当調整。`event` と共に記録。

### 3.2 検証手続き（探索パラメータの一意確定＝採否決定）

```
S1. 時系列分割：IS（前半70%）/ OOS（後半30%）。OOSは封印。
S2. IS：全20候補のf_k（コスト控除後・週次純リターン平均）を算出。
S3. IS：Hansen SPA を適用。
     帰無 H0：max_k E[f_k] ≤ 0
     統計量：V = max_k √n·f̄_k
     帰無分布：定常ブートストラップ（Politis-Romano、B=5000）
              ブロック長：Politis-White (2004) で自動選択
     p値：再センタリング後のV*_bが観測Vを超える割合
S4. 判定：
     p ≥ 0.05 → 戦略棄却（採用候補なし・運用しない）。終了。
     p < 0.05 → f_kが最大かつf_k>0の候補を「選択候補」とする。
S5. OOS：選択候補のみを、触れていないOOS区間で1回だけ実行（コスト込み）。
S6. 採否（一意）：OOSで
     (a) 週次純リターン平均 > 0、かつ
     (b) ストップ到達率が Kupiec検定 p≥0.05、かつ
     (c) Christoffersen独立性検定 p≥0.05
     を全て満たす → 採用。1つでも欠ければ不採用。
```

→ S1〜S6は決定論的。同一データから**選択パラメータ・採否が一意に定まる**。

## 4. 非機能要件（定量基準）

### 4.1 検証の合否しきい値

| 項目 | 要件 |
|---|---|
| データスヌーピング | SPA p < 0.05（S4） |
| ストップ被覆 | Kupiec p ≥ 0.05（実到達率 ≈ α_stop=0.05） |
| ストップ独立性 | Christoffersen p ≥ 0.05 |
| 利確校正 | T到達率 と p_tp の差 ≤ ±5%ポイント |
| OOS期待値 | 週次純リターン平均 > 0 |
| サンプル | 検証週数 ≥ 260、ストップ到達 ≥ 30回（複数年プール） |
| look-ahead | σ̂・S・T・N の計算に当日以降のH/L/C不使用（依存グラフ検証） |
| 再現性 | 同一データ・同一乱数シードで SPA p値が一致（シード固定） |

### 4.2 ログ項目（観測可能性）

週ごとに：
`week_id, O, σ̂⁺_w, σ̂⁻_w, S, T, N, entry_flag, exit_type(利確/ストップ/時間切れ), 保有日数, gross_pnl, cost, net_pnl, event_flag`

## 5. 制約・前提条件

- 取引対象は現物指数CFDであり、約定価格はブローカー提示値（取引所単一正本なし）。検証は実取引ブローカー価格で行うことが望ましく、Dukascopy は代理データ。
- 現物指数CFDは保有時にファンディングが発生し、配当落ち日に価格調整が入る（§3.1-8 に反映）。
- バリア分布仮定（§2.3）は近似。校正（§4.1）不合格時は、本仕様を改版し経験分布版へ差し替える（改版手続きで対応、本版の範囲外）。
- σ̂ が予測するのは変動の大きさ（バンド幅）のみ。利確到達の方向確率にエッジがあるか否かは、エントリー規則の探索（§2.4 E1）と SPA/OOS（§3.2）で**データから決定**され、本仕様内に未定の自由度は残さない。

## 数値例（一意性の確認）

入力：`O=39000, σ̂⁻_w=0.020, σ̂⁺_w=0.025, p_tp=0.50, Capital=1,000,000円, f_risk=0.01`

- `S = 39000·exp(−1.96·0.020) = 39000·exp(−0.0392) = 37,501`
- `z(0.50)=0.674` → `T = 39000·exp(0.674·0.025) = 39000·exp(0.01685) = 39,663`
- ストップ距離 = 1,499（3.84%）、利確距離 = 663（1.70%）、R = 663/1499 = 0.442
- ドリフトなし基準勝率 = 1499/(1499+663) = 69.3%（＝1/(1+R)）→ この候補で勝つには実測勝率が69.3%超必要
- `N = 0.01·1,000,000 / 1,499 = 6.67 単位`

→ 同じ入力なら、誰が計算しても S=37,501・T=39,663・N=6.67 で一致。
