# btlm_track 事前分析 結論整理（2026-07-19）

新指標 btlm_track の設計に先立ち実施した実証分析の結論をまとめる。
すべての数値は **実測値** である（憶測・理論値ではない）。測定条件は §2 参照。

---

## 1. 用語集（本書を読むための定義）

| 用語 | 定義 |
|---|---|
| **tgp_btlm** | 既存インジケーター。価格系列に「区分線形ベイズ回帰」を当てはめ、予測平均と上下の帯を描く。本分析はその numpy 参照実装（ols）を対象とした。 |
| **ols（回帰直線）** | 最小二乗法による直線当てはめ。直近 maxbars 本の価格に「もっとも当てはまる 1 本の直線」を引く操作。実装は `OlsBtlmFitter`（木分割・乱数なし＝決定論）。 |
| **maxbars（窓）** | 直線を当てはめる対象となる「直近の本数」。例: maxbars=100 なら直近 100 営業日で 1 本の直線を引く。この範囲を「窓」と呼ぶ。 |
| **ドット（窓末尾値）** | 各営業日で窓を当てはめ直し、その直線の**当日位置の値**（`btlm_mean` の末尾）を 1 点打ったもの。本指標の原子。確定日の値は以後変わらない（非リペイント）。 |
| **β（ベータ・傾き）** | 当てはめた直線の傾き（回帰係数）。「1 日あたり価格が何ポイント進むトレンドか」を表す。トレンド方向の**正式な判定値**。 |
| **残差** | 実際の価格と回帰直線との差。「価格が直線からどれだけ外れているか」。 |
| **q5 / q95（予測分位点）** | 「残差が正規分布に従う」と仮定した場合に、価格の 90% が収まるとされる帯の下端・上端。半幅 ≒ 1.645 ×（窓内の残差標準偏差）。 |
| **被覆率** | 実際の価格が帯 [q5, q95] の中に収まった日の割合。**名目被覆率**は理論上の設計値（90%）、**実被覆率**は実データで測った実際の割合。 |
| **LSMA** | Least Squares Moving Average。回帰直線の終端を繋いだ移動平均の一種。本指標のドット系列は数学的にこれと同一。遅れ（ラグ）が小さいことで知られる。 |
| **MA（移動平均）** | 直近 N 日の単純平均等。トレンド相場では構造的に価格から遅れる（傾き × 約 N/2 日分）。 |
| **乖離率** | （価格 − 基準線）÷ 基準線。基準線からどれだけ離れているかの比率。 |
| **平均回帰** | 「大きく離れた値はやがて基準へ戻る」という性質。戦略の前提にできるかは実測で確認が必要。 |
| **t 値** | 測定した平均値が「偶然ゼロでない」と言える度合い。目安として \|t\|≥2 で統計的に有意。ただし標本数が少なければ意味を持たない。 |
| **経験分位** | 正規分布などの仮定を使わず、実測データを並べて「下から 5% 目・95% 目」の実際の値をそのまま使う方法。 |
| **無条件確率 / 条件付き確率** | 無条件＝「普段の日を全部数えた」割合（例: 被覆率 88.6%）。条件付き＝「特定の状況が起きたときだけ数えた」割合（例: 帯の端に到達した直後）。**両者は別物で、無条件の数値を条件付きの場面に流用してはいけない**（本分析で最も重要な注意点）。 |
| **MAE（最大逆行）** | Maximum Adverse Excursion。エントリーしてから測定期間内に、価格が一番不利な方向へ動いた幅。「ストップがどこまで耐える必要があるか」の実測値。 |
| **生存確率** | 指定した期間、ストップに掛からずにポジションが残る確率。ストップ距離を MAE の分位数に合わせることで設計できる。 |
| **σ 正規化** | 距離を「その日の残差 σ（回帰直線まわりの価格の散らばり）の倍数」で表すこと。ボラティリティ局面が変わっても自動で追随する。 |

## 2. 測定条件（すべての結論の前提）

- データ: JP225（NI225）日足 1,500 本（実 HTTP 経路 `/candles` から取得した本番同一データ）
- 実装: リポジトリの実装実体（`indigators/tgp_btlm/src/reference.py`・`bands.py`）を直接呼び出し
- 方法: 各営業日で直近 maxbars 窓を当てはめ直すローリング計算（既定 maxbars=100・約 1,400 回）
- 限界: 単一銘柄・単一期間（約 5.5 年・上昇基調）・取引コスト未考慮。§6 参照

## 3. 最重要の結論（A〜E）

### 結論 A: バンドの正体は「ドット線からの価格乖離の統計量」である
btlm の帯の半幅は **1.645 ×（窓内の残差標準偏差）**（終端の補正項は +1〜2% で無視可・実測）。
つまり帯とは「価格の対ドット乖離が正規分布に従うと**仮定**して ±1.645σ を引いた線」に過ぎない。
→ **「ドット平均線からの価格の上下乖離率で実被覆率を測れるのでは」という着想は、実装の数理と完全に一致する（正しい）。**

### 結論 B: 名目 90% は達成されず、実被覆率は maxbars に依存して悪化する

| maxbars | 当日実被覆率（名目 90%） |
|---|---|
| 20 | 86.8% |
| 50 | 80.6% |
| **100（既定）** | **78.7%** |
| 200 | 74.3% |
| 400 | 69.4% |

原因: 実際の乖離分布は正規仮定より裾が厚く、窓が長いほど「直線モデルの不適合」が混入するため。
帯の幅は市場ボラティリティ（相関 0.62）と不適合度（相関 0.62）の**両方**で広がる＝幅の拡大をリスク増大と断定できない。

**【実証済み 2026-07-19】経験分位バンドはウォークフォワードで被覆率をほぼ名目まで回復する。**
過去 N 日の乖離率の経験 5%・95% 分位で帯を引き、**翌時点**（厳密に因果＝未来情報なし）の被覆率を全 14 年で測定：

| 帯の引き方 | 日足被覆率 | 1h 足被覆率 |
|---|---|---|
| 名目 ols バンド（正規仮定） | 77.2% | 76.7% |
| 経験分位 N=125 | 82.7% | — |
| 経験分位 N=250 | 87.1% | 86.6% |
| 経験分位 N=500 | **88.6%** | — |

N を長くするほど名目 90% に接近（残る 1〜3pp の不足はボラ局面変化に分位が遅れるため）。時間足を替えても改善幅は同等（+10pp）＝頑健。**設計代替案として実証成立。**

### 結論 C: 価格の対ドット下方乖離の平均回帰 —【検証済み 2026-07-19】方向は再現するが効果は当初推定の半分・単独では戦略化不十分

初回推定（直近 1,500 日・重複窓あり・5% 乖離→21 日先 +4.86%）を、全 14 年データ（3,676 日）＋非重複エピソード＋ブートストラップ p 値で厳密に再検証した結果：

| 検証区間 | 件数 | 条件付き 21日先 | 無条件 | 超過 | p 値 | 21日内回帰率 |
|---|---|---|---|---|---|---|
| **アウトオブサンプル（2012-2020）** | 21 | +2.68% | +1.14% | +1.54pp | 0.100 | 52% |
| インサンプル（2020-2026） | 15 | +3.45% | +1.68% | +1.77pp | 0.093 | 53% |
| 全期間プール | 36 | +3.00% | +1.37% | +1.63pp | **0.036** | 53% |
| 1h 足・前半（閾値=分布p5） | 137 | +0.17% | +0.02% | +0.15pp | 0.085 | 50% |
| 1h 足・後半 | 150 | +0.12% | +0.08% | +0.03pp | 0.374 | 35% |

**確定した事実：**
1. **方向の再現性はある**：全 5 区間すべてで超過が正（未知期間 2012-2020 でも +1.54pp）。偶然でここまで揃う可能性は低い。
2. **効果量は当初推定の約半分**：初回の +4.86% は重複エピソードによる過大推定。非重複では +3.00%（全期間）。
3. **単独の統計的有意性はない**：どの分割区間も p≈0.09〜0.37 で有意水準 5% に届かず、プール時のみ p=0.036。
4. **非対称**：上方 +5% 乖離にショート側の優位性は無い（OOS 超過 +0.05pp・p=0.51）＝効くとしてもロング側のみ。
5. **21 日内回帰率は 52〜53%**（初回の 57% から低下）。「回帰する」というより「わずかに戻りやすい」程度。

**判定：仮説→「弱い正の傾向として再現・ただし単独では戦略化不十分」に格下げ確定。** 戦略にするならフィルタの一要素（他シグナルとの併用）が上限。

### 結論 D: バンド下端エントリーの本当のリスク —【実証済み 2026-07-19】88.6% はタッチの瞬間には適用できない

**問い**：「被覆率 88.6% なら、帯の下端で買えば、そこから外へ出る可能性は低い（＝直後にマイナスになりにくい）のでは？」

**答え**：**いいえ。これは無条件確率と条件付き確率の取り違えである。** 88.6% は「普段の日」を全部数えた割合。帯の端に価格が来るのは、ボラ拡大・下落モメンタムがまさに進行中の局面であり、その直後だけを数えると景色が一変する。

下端初割れ後の実測（1h 足 × 日次経験分位バンド・79 イベント・2017〜2026）：

| タッチ後 | まだ帯外にいる率 | 最大逆行 >0.5% の率（無条件比） | 最大逆行 >1% の率（無条件比） | リターン中央値 |
|---|---|---|---|---|
| +1h | **75%** | 23%（**3.3 倍**） | 9%（9 倍） | +0.02% |
| +8h | 56% | 58%（1.4 倍） | 33%（**2.2 倍**） | +0.13% |
| +24h | **37%** | 73%（1.2 倍） | 48%（1.4 倍） | +0.69% |

日足ベース（帯下端タッチ 40 回）でも同様: 5 日以内の最大逆行は中央値 2.10%（無条件 1.51%）、5% 超の逆行率 25%（無条件 7% の **3.6 倍**）。

**確定した事実**：
1. 割った直後は「帯外にいること」が常態（+1h で 75%）。短期逆行の発生率はどのホライズンでも無条件の 2〜3 倍。「直後にマイナスになりにくい」は不成立。
2. **ただし逆行の絶対量は浅い**（+1h 中央値 0.22%・+24h 中央値 0.95%）。リターン中央値はゼロ近辺〜プラス。
3. **24 時間以内に 63% が帯内へ回帰する**——これが終値被覆率 88.6% の成立機序。「当日〜翌日で帯内へ戻りやすい」は正しい。
4. 正確な表現：「マイナスにならない」ではなく「**マイナスは浅く・短く済みやすい**」。帯端エントリーはタイトなストップと相性が最悪で、帯外滞在に耐える設計とだけ整合する。

### 結論 E: ストップ距離は統計的に導出できる —【実証済み 2026-07-19】

ストップ距離＝「タッチ後 MAE の条件付き分位数」とすれば、狙った生存確率を距離に翻訳できる：

| 生存確率（刈られない確率） | +8h の距離 | +24h の距離 | σ 正規化（+24h） |
|---|---|---|---|
| 75% | 1.11% | 2.13% | 0.58σ |
| **90%** | 1.61% | **2.77%** | **1.14σ** |
| 95% | 2.09% | 3.37% | — |

- 読み方：「エントリー後 24 時間を 90% の確率で生き残る」なら帯下端から 2.77% 下にストップ。
- **σ 正規化版が実用形**：距離を「その日の残差 σ の倍数」（例: 24h・90% → 1.14σ）で持てば、ボラ局面の変化に自動追随する。σ は同じ回帰フィットから毎日得られる＝追加コストなし。
- 留意：①標本 79 件のため p90/p95 の推定は粗い（別期間で要再検証）、②帯端ちょうどのストップは論外（75% が帯外継続のためほぼ即死）、③これは「刈られない距離」であり「儲かる距離」ではない（生存とエッジは別問題。エッジの上限は結論 C の弱い戻り傾向）。

## 4. ドット・β・MA の役割分担（実測に基づく整理）

| 知りたいこと | 使うべき量 | 根拠（実測） |
|---|---|---|
| トレンドの現在位置 | **ドット**そのもの | 価格にラグ 0 で追随（LSMA 終端）。予測力はゼロ（翌日方向 ≈50%）＝記述量 |
| トレンドの方向・傾き | **β の符号・値** | 定義上厳密。ドット前日比の符号は 63.9% しか一致しない（3 回に 1 回誤る） |
| 行き過ぎ（売られ過ぎ等） | **価格 − ドットの乖離率** | トレンド成分を除去した純粋な残差。MA 乖離は「トレンドの遅れ」が混入し不適 |
| 方向のゆるい確認（補助） | ドットの MA（21 本で一致率 73.8%） | 機能はするが β の劣化版。長いほど一致率向上 |

### MA について確定した事実
- ドット系列に MA を重ねる（二重平滑）と日次の値動きとの連動がほぼ消える（相関 0.02）＝分析情報はほぼ失われる。
- ドット差分の**微分**（2 階差分＝加速度）は符号一致率 55.5% ＝ノイズに埋もれて読めない。
- ドット差分の**積分**（N 日累和）は数学的に「N 日変化」に等しく、MA の傾きと**情報として等価**（一致率が完全一致）。新しい知見は増えない。

### 「MA 乖離」と「ドット乖離」の意味の違い（結論 5）
- **通常の MA 乖離** ＝「トレンドの遅れ」＋「行き過ぎ」が混ざった量。トレンド中は常に乖離が出っぱなしになり、売られ過ぎ・買われ過ぎとは読めない。
- **ドット乖離** ＝ 遅れ成分を除去した「行き過ぎ」そのもの（回帰の残差）。
- 実測でも、ドット基準の回帰は価格上昇主導（寄与 0.6〜0.9）だが、MA 基準は回帰率 45〜56% に低下し短期は逆行。**ドット基準が合理的**。

### 成立しなかった戦略（棄却済み）
- 「**ドット**が MA から n% 乖離 → MA へ回帰」: 不成立。21 日内回帰は 2 割弱で、閉じる場合も「MA が下がって追いつく」見かけの回帰。イベントも希少（5.5 年で 6〜11 回）。

## 5. 反証テストで撤回した当初懸念（記録）

| 当初の懸念 | 実測結果 | 判定 |
|---|---|---|
| 窓終端は分散最大で不安定 | 半幅は窓内中央値比 +1.1% のみ | 撤回（無視できる） |
| in-sample 値ゆえ歪む | 当日除外の外挿予測との差 0.12% | 撤回（値として同等） |

| 合成ソース（hl2 等）が帯を狭める | hl2/close 半幅比 0.979（2% 差） | 撤回（無視できる） |

## 6. 証拠の限界（すべての結論に共通）

1. 単一銘柄（JP225）での測定（期間は 2026-07-19 の追検証で 14 年・2012〜2026 に拡張済み。時間足も 1h で頑健性確認済み）。
2. 結論 C の閾値（5%）は初回分析での事後選択（追検証では同一閾値を事前固定して期間分割・重複補正・対称性検定を実施済み。§3 結論 C の表参照）。
3. 取引コスト・スリッページ未考慮。
4. ols は単一区分線形（木分割なし）。レジーム転換の表現力は元々ない（参照実装の自認）。
5. 追検証の計算は閉形式の高速実装によるが、参照実装 `build_btlm_bands` との一致を数値検証済み（最大差 1e-6 未満）。

## 7. 設計への反映（btlm_track 確定仕様との対応）

| 結論 | 仕様への反映 |
|---|---|
| A・B | 実現被覆率を直近 N 日（既定 250）でローリング実測し数値表示。帯は参照実装のまま（校正しない）。**経験分位バンドはウォークフォワード実証済み（88.6% @N=500）**——標準装備するかオプションにするかはユーザー裁定待ち |
| C | 検証済み：弱い正の傾向（単独では戦略化不十分・ロング側のみ）。指標の機能・保証には含めない（分析知見として本書に記録） |
| D | 「帯＝安全なエントリー水準」という解釈を非保証事項へ明記（無条件被覆率は条件付き場面に流用不可）。帯幅は乖離スケールの記述量としてのみ利用 |
| E | 残差 σ は表示候補（σ 正規化ストップ距離の計算資源。同一フィットから毎日得られる）。標本拡充後の再検証を経て拡張候補 |
| 方向判定 | β を数値表示（方向の正式判定値）。ドット前日比での方向判定は非保証事項に明記 |
| MA | `btlm_mean` のみ・既定オフの「方向確認用参考線」に格下げ（種別/ソースは moving_averages 同期） |
| 予測力なし | 「予測値ではない」ことを非保証事項の筆頭に明記 |
