## 2. 下方バンド・ケリー基準ナンピン（エピソード方式）

規約: q5 終値下抜け→翌寄第 1 段、保有中 med_lo/ext_lo 下抜けで追加（各 1 回）、q5 終値
上抜けで翌寄全決済・20 営業日タイムアウト。61 トレード（ナンピン発動 16・3 段目 3）・平均保有 3.9 日。

連続ケリー f=μ/σ²（各ライン h=10 実測・インサンプル）: q5=3.74 / med=6.45 / ext=4.34（計 14.5 倍）。

| 賭け方 | CAGR | 最大DD | 備考 |
|---|---|---|---|
| フルケリー（c=1.0） | **破産** | −100% 超 | 2024 暴落 1 トレード（3 段発動・素損益 −8.75%）で資本喪失 |
| c=0.5（対数成長の実測最適） | +9.5% | −66% | 実用外の DD |
| c=0.2（1/5 ケリー） | +4.8% | −28% | |
| c=0.1（1/10 ケリー） | +2.5% | −14% | 実用推奨域 |
| 等ウェイト 1/3（合計 100%） | +2.0% | −9% | |
| q5 単発 100% | +3.4% | −15% | |

- **med_lo までの 2 段構成は全水準で 3 段版に劣後し破産も回避できない**（最悪トレード素損益が
  −8.75%→−13.05% に悪化。最深部で買う 3 段目が平均回帰の取り分最大のため）。
- ナンピンは勝率を 80→84% に上げるが、総資本 100% 制約下では q5 単発に劣る（深い段が稀で待機資本が遊ぶ）。
- エッジの源泉は**エントリー水準**であり、ナンピン構造・ケリー配分ではない。

### 2.1 具体運用（1/10 ケリー相当）

資金比 想定元本: 第 1 段 37%・第 2 段 65%・第 3 段 43%（全段発動 145%）。
10 万円口座では×1 円ミニ CFD「各段 1 枚」が同水準（実測: 年 +3.8%・最大 DD −18%・最悪 1 トレード −16%）。
「1 枚/1 枚/2 枚」は年 +4.8%・DD −17% で小口径の実測最良。**×10 円 CFD は 1 枚で 6.6 倍レバ＝フルケリー超のため 10 万円口座では使用禁止**。
証拠金余力まで枚数を増やすのは検証の前提を破壊する（枚数は証拠金でなく想定元本で決める）。
