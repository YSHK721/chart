Summary

要点

  • ローカルの先物miniは 2024/12/30 00:00 JST から 2026/01/05 23:59 JST の時系列を持つ。
  • CSV と Dukascopy は UTC に変換して比較し、278,801 行が一致した。
  • 市場時間帯である 09:00〜15:00 JST では、先物miniと CFD の 1分足方向性がかなり一致する。
  • 15:00以降は相関が急落し、18:00〜23:00 JST はほぼ無相関に近くなる。
  • 翌朝の 09:00前後で相関が再び立ち上がるため、時間帯依存性が明確である。
  • ここでの「相関」は価格の return 相関、方向一致率、出来高相関の3指標を別個に扱う。

相関の成立条件

日本市場の 09:00〜15:00 JST が相関高く、16:00以降の非市場時間帯は相関が弱くなることが実測で確認された。

Interpretation

解釈

1分足の全期間相関が低いのは、夕方〜夜間の低相関時間帯が全体を引き下げているためである。
逆に、09:00〜15:00 JST の通常取引時間帯では、先物miniと CFD の方向性が高い水準で一致している。

  • 深夜 01:00〜05:00 JST に相関が再度上昇することは実測で確認された。
  • この再相関の背景としては、夜間の市場構造や海外市場の影響が相対的に強くなることが考えられるが、個別要因は追加検証が必要である。
  • 実証済みなのは「時間帯依存の変動」であり、特定市場要因の断定までは行わない。
Volume by session

時間帯別の出来高と価格相関の関係

先物miniの出来高と Dukascopy の tick volume（bidVolume + askVolume）を同じ JST の時間帯で比較したところ、 価格相関が高い時間帯ほど両者の流動性も高いことが確認された。

JST 時間帯 先物mini 出来高 Dukascopy tick volume 価格相関の状態
09:00〜15:00 高い 高い 高相関
15:00〜23:00 低い 低い 低相関 / 無相関
01:00〜05:00 回復 回復 再び高相関

ここでの Dukascopy volume は、各 tick の bidVolume と askVolume を合計した値を 1 時間ごとに集約したもの。
つまり、相関が高い時間帯では「両市場ともに取引が活発で、板が厚くなっている」ことを示す。
これは価格相関の説明であり、出来高同士の数値相関を意味するものではない。
